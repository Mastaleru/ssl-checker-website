개인정보처리방침

최종 업데이트: 2026년 10월 30일

이 페이지는 번역본입니다. 영어 버전과 내용이 다를 경우 영어 버전이 우선합니다.

SSL Checker는 활성 탭에 열린 웹사이트의 TLS 인증서를 보여 주고, 이를 인터넷의 다른 위치에 있는 공증 서버가 보는 인증서와 비교하는 브라우저 확장 프로그램입니다.

확장 프로그램이 읽는 정보. 팝업을 열 때만, 그리고 팝업에서 동의한 후에만 다음 정보를 읽습니다. 활성 탭의 주소(검사할 사이트를 알기 위해)와, 브라우저에서 읽기가 사용 설정된 경우 Chrome의 디버거 인터페이스를 통해 읽은 해당 탭의 인증서 체인 및 연결 매개변수입니다. 페이지 콘텐츠, 쿠키, 비밀번호, 양식 데이터, 다른 탭 또는 인터넷 사용 기록은 읽지 않습니다.

기기 밖으로 전송되는 정보. 동의하기 전에는 아무것도 전송되지 않습니다. 동의한 후 사이트를 검사하면 해당 사이트의 호스트 이름과 포트가, 사용 중지하지 않은 경우 SSL Checker 개발자가 운영하는 PlusPrivacy 공증 서버(notary.plusprivacy.com)로 전송되고, 옵션에서 추가한 공증 서버에도 전송됩니다. 이때 해당 서버에 입력한 액세스 토큰이 있으면 함께 전송됩니다. 각 요청에는 응답이 그 요청에 대해 만들어졌는지 확인하는 데만 사용되는 난수도 포함됩니다. 그 밖에 개발자에게 전송되는 정보는 없습니다. 분석, 추적, 광고 및 계정은 없습니다.

PlusPrivacy 공증 서버. 공증 서버는 호스트 이름과 포트를 해당 사이트에 연결하여 사이트가 제시하는 인증서를 반환하는 데만 사용합니다. 디스크에는 아무것도 쓰지 않으며 검사한 사이트에 대한 기록을 남기지 않습니다. 요청마다 같은 사이트에 다시 연결하지 않도록 각 응답을 메모리에 60초 동안 보관하며, 남용을 막기 위해 네트워크 주소별로 요청 수를 셉니다. 남용하는 주소는 최대 24시간 동안 차단되며 공증 서버의 로그에 기록됩니다. 공증 서버로 보내는 모든 요청은 암호화(HTTPS)되며, 사이트 이름은 요청 본문에 담겨 전송되고 요청 주소에는 절대 포함되지 않습니다. 공증 서버는 각 응답에 서명하므로 확장 프로그램은 응답이 전송 중에 변경되지 않았는지 확인할 수 있습니다.

저장되는 정보. 사용자의 동의와 설정(PlusPrivacy 공증 서버 사용 여부, 읽기 모드, 공증 서버 주소, 토큰 및 키, 대기 시간)은 기기의 chrome.storage.local에 저장됩니다. 각 탭의 마지막 검사 결과는 chrome.storage.session에 보관되며, 탭이나 브라우저를 닫으면 삭제됩니다. 사이트 기억이 사용 설정된 경우(브라우저에서 인증서를 읽을 때의 기본값) 검사한 각 사이트의 호스트 이름과 해당 사이트가 사용한 인증 기관(이름, 키 지문, 날짜, 검사 횟수)도 chrome.storage.local에 저장되며, 이는 사이트가 갑자기 다른 인증 기관을 제시할 때 SSL Checker가 경고할 수 있도록 하기 위한 것입니다. 시크릿 창에서는 아무것도 기록되지 않습니다. 이 데이터는 기기 밖으로 나가지 않습니다. 옵션에서 사이트 기억을 사용 중지하거나 삭제할 수 있으며, 400일 동안 검사하지 않은 사이트는 자동으로 삭제됩니다.

제3자. 사용자가 추가하는 공증 서버는 사용자 본인 또는 사용자가 선택한 운영자가 운영하며, 해당 운영자의 정책이 적용됩니다. SSL Checker가 처리하는 데이터의 사용은 제한적 사용(Limited Use) 요구사항을 포함한 Chrome Web Store 사용자 데이터 정책을 준수합니다.
