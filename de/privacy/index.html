Datenschutzerklärung

Zuletzt aktualisiert: 30. Oktober 2026

Diese Seite ist eine Übersetzung. Bei Abweichungen von der englischen Fassung gilt die englische Fassung.

SSL Checker ist eine Browsererweiterung, die das TLS-Zertifikat der Website in Ihrem aktiven Tab anzeigt und es mit dem vergleicht, was Notarserver von anderswo im Internet sehen.

Was die Erweiterung ausliest. Nur wenn Sie ihr Pop-up öffnen, und erst nachdem Sie dort zugestimmt haben: die Adresse des aktiven Tabs (um zu wissen, welche Website geprüft werden soll) und, falls das Auslesen aus dem Browser aktiviert ist, die Zertifikatskette und die Verbindungsparameter dieses Tabs, ausgelesen über die Debugger-Schnittstelle von Chrome. Seiteninhalte, Cookies, Passwörter, Formulardaten, andere Tabs und Ihren Browserverlauf liest die Erweiterung nicht.

Was Ihr Gerät verlässt. Nichts, bevor Sie zustimmen. Danach werden beim Prüfen einer Website deren Hostname und Port gesendet: an den PlusPrivacy-Notar (notary.plusprivacy.com), den der Entwickler von SSL Checker betreibt, sofern Sie ihn nicht deaktiviert haben, und an die Notarserver, die Sie in den Optionen hinzufügen, zusammen mit dem Zugriffstoken, das Sie gegebenenfalls für einen Server eingegeben haben. Jede Anfrage enthält außerdem eine Zufallszahl, die nur dazu dient, zu prüfen, ob die Antwort für diese Anfrage erstellt wurde. Sonst wird nichts an den Entwickler gesendet. Es gibt keine Analysedienste, kein Tracking, keine Werbung und kein Konto.

Der PlusPrivacy-Notar. Er verwendet Hostname und Port nur, um sich mit dieser Website zu verbinden und das Zertifikat zurückzugeben, das die Website vorlegt. Er schreibt nichts auf einen Datenträger und führt keine Aufzeichnungen über die geprüften Websites. Im Arbeitsspeicher behält er jede Antwort 60 Sekunden lang, damit eine Website nicht bei jeder Anfrage erneut kontaktiert wird, und er zählt die Anfragen pro Netzwerkadresse, um Missbrauch zu unterbinden; eine Adresse, die ihn missbraucht, wird für bis zu 24 Stunden gesperrt und erscheint in seinem Protokoll. Alle Anfragen an ihn sind verschlüsselt (HTTPS), und der Name der Website wird im Body der Anfrage übertragen, nie in ihrer Adresse. Er signiert jede Antwort, damit die Erweiterung erkennen kann, dass sie unterwegs nicht verändert wurde.

Was gespeichert wird. Ihre Zustimmung und Ihre Einstellungen (PlusPrivacy-Notar ein oder aus, Auslesemodus, Notaradressen, Tokens und Schlüssel, Wartezeit) werden mit chrome.storage.local auf Ihrem Gerät gespeichert. Das Ergebnis der letzten Prüfung für jeden Tab wird mit chrome.storage.session aufbewahrt und gelöscht, wenn Sie den Tab oder den Browser schließen. Wenn das Website-Gedächtnis aktiviert ist (die Standardeinstellung, wenn das Zertifikat aus dem Browser ausgelesen wird), werden außerdem der Hostname jeder geprüften Website und die Zertifizierungsstelle, die sie verwendet hat (Name, Fingerabdrücke der Schlüssel, Datumsangaben und Anzahl der Prüfungen), mit chrome.storage.local gespeichert, damit SSL Checker Sie warnen kann, wenn eine Website plötzlich eine andere Zertifizierungsstelle vorlegt. Aus Inkognitofenstern wird nichts erfasst. Diese Daten verlassen nie Ihr Gerät; Sie können das Website-Gedächtnis in den Optionen deaktivieren oder löschen, und Websites, die 400 Tage lang nicht mehr gesehen wurden, werden automatisch gelöscht.

Dritte. Die Notarserver, die Sie hinzufügen, werden von Ihnen oder von jemandem Ihrer Wahl betrieben; für sie gelten deren eigene Richtlinien. Die Verwendung der Daten, die SSL Checker verarbeitet, entspricht der Chrome Web Store User Data Policy, einschließlich der Limited-Use-Anforderungen.
